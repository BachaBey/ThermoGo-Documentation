# Brand — ThermoGo Visual Identity

This folder contains all brand assets for ThermoGo, including logo files, color palette, and typography guidelines.

## Contents

```
Brand/
├── Logo/
│   ├── ThermoGo_Logo_Primary.svg      # Full color logo (light background)
│   ├── ThermoGo_Logo_Dark.svg         # White logo (dark background)
│   ├── ThermoGo_Logo_Primary.png      # PNG @ 1024×1024px
│   ├── ThermoGo_Logo_Dark.png         # PNG @ 1024×1024px
│   └── ThermoGo_Icon.png              # Square app icon @ 512×512px
├── Colors.md                          # Brand color palette
├── Typography.md                      # Font choices and usage
└── README.md
```

## Color Palette

| Name | Hex | Usage |
|---|---|---|
| Primary Blue | `#1A73E8` | Main brand color, buttons, highlights |
| Alert Red | `#E53935` | Fever alerts, warnings |
| Safe Green | `#43A047` | Normal temperature indicator |
| Cool Teal | `#00ACC1` | Hypothermia indicator, accents |
| Dark Charcoal | `#212121` | Text, dark backgrounds |
| Light Grey | `#F5F5F5` | Card backgrounds, surfaces |

## Typography

| Role | Font | Weight |
|---|---|---|
| Headings | Inter | 700 (Bold) |
| Body text | Inter | 400 (Regular) |
| Temperature readout | Roboto Mono | 700 (Bold) |
| Labels / captions | Inter | 500 (Medium) |

Both fonts are available free from [Google Fonts](https://fonts.google.com).

## Logo Usage Guidelines

- Minimum size: 32px height (digital), 10mm height (print)
- Always maintain clear space of at least 50% of logo height on all sides
- Do not stretch, rotate, or recolor the logo
- Use the dark variant on backgrounds darker than `#888888`
- Do not place the logo over busy photographs without a backing panel

## App Icon

The square app icon (`ThermoGo_Icon.png`) is formatted for submission to the Google Play Store and Apple App Store at 512×512px with no rounded corners applied (stores apply their own masks).
