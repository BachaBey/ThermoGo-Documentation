## Report Structure

The report covers the following sections:

1. **Abstract** — Project summary and key outcomes
2. **Introduction** — Problem statement, motivation, and objectives
3. **Literature Review** — Existing thermometer solutions and gap analysis
4. **System Design**
   - Hardware architecture
   - Firmware design and BLE protocol
   - Mobile application architecture
   - PCB schematic and layout
   - 3D enclosure design
5. **Implementation**
   - Component selection and justification
   - Circuit assembly and testing
   - Firmware development
   - Mobile app development
6. **Results & Testing**
   - Temperature accuracy measurements (vs. clinical reference)
   - BLE range and latency benchmarks
   - Battery life tests
   - User testing feedback
7. **Discussion** — Challenges faced, solutions applied, limitations
8. **Conclusion & Future Work**
9. **References**
10. **Appendices** — Schematics, code listings, data sheets
