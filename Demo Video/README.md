# Demo Video — ThermoGo in Action

This folder contains the product demonstration video showcasing ThermoGo's full functionality.

## Contents

```
Demo Video/
├── ThermoGo_Demo.mp4     # Full product demonstration (~3–5 min)
└── README.md
```

## What the Demo Covers

1. **Device power-on** — pressing the power button, OLED startup screen
2. **BLE pairing** — opening the mobile app, scanning, and connecting to ThermoGo
3. **Live temperature measurement** — pressing the trigger, sub-second reading display on both OLED and app
4. **Fever alert** — demonstrating a simulated high-temperature alert with push notification
5. **History log** — scrolling through past readings with timestamps
6. **Temperature chart** — viewing the trend graph across multiple sessions
7. **Settings** — switching between °C and °F, adjusting alert thresholds
